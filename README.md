源码仓库：https://github.com/Notesae/poe2-util-zh

## 源码安装与发布

克隆仓库后可直接在浏览器扩展管理页加载 `extension` 文件夹。弹窗采用双列小卡片，七个模块同屏设置；汉化与双语开关分别保存。

仓库不跟踪 `dist`、压缩包、浏览器测试配置和截图。内置 `extension/data.js` 是运行时必需词库，随源码保留。

发布时先让 `extension/manifest.json` 与 `package.json` 的版本号一致，再推送对应 `v版本号` tag，例如 `v0.2.0`。GitHub Actions 会检查词库、打包并将 ZIP 附加到该 tag 的 GitHub Release；产物不会提交回仓库。本次只上传源码，尚未创建发布 tag。

本地打包：`python tools/release.py`。输出到 `dist`，不需要下载资料或安装额外 Python 包。

## 0.2.0：独立网站模块

保留市集汉化，新增六个网站模块。扩展弹窗中每个模块有独立的「启用汉化」和「中英双语」开关；设置跨页面保存。旧版市集开关和双语偏好自动兼容。网站模块没有共用总开关，关闭一个不会关闭其他模块。

| 模块 | 范围 |
| --- | --- |
| PoE2 市集 | 国际服 `/trade2/`，保留筛选接口及交易结果汉化 |
| NINJA | `poe.ninja/poe2/`，行情、构筑界面及词库内物品 |
| POBb.in | `pobb.in`，分享界面、属性标签及词库内游戏文本 |
| Maxroll | `maxroll.gg/poe2`，导航、流派栏目及词库内游戏文本 |
| Mobalytics | `mobalytics.gg/poe-2`，流派、指南栏目及词库内游戏文本 |
| Craft of Exile | 主站及 `beta.craftofexile.com`，制作工具标签及词库内游戏文本 |
| Path of Exile 官网 | 国际服官网导航和按钮；不接管 PoE1 市集，PoE2 市集单独控制 |

新增网站模块即时切换、关闭恢复原文；市集修改设置会刷新页面。NINJA、Maxroll、Mobalytics 切换到其他游戏路径时恢复原文。POBb.in 和 Craft of Exile 共用入口也可能包含 PoE1 内容，本插件游戏词库以 PoE2 为准。

**覆盖边界**：这是本地词库汉化，不是全文翻译服务。已添加各网站常见界面标签；装备、技能和词缀复用现有词库。未知文本、攻略正文、用户帖子、图片、Canvas 和跨节点组合文本不保证翻译。新模块不修改网络请求、表单输入值、链接地址和构筑导入代码；常见账号/作者区域跳过翻译。未匹配清单可从当前页导出。

升级：在浏览器扩展管理页刷新插件，再刷新已经打开的网站。若安装的是 `dist/poe2-trade-zh/extension`，使用本次同步后的目录，或重新解压新版安装包。

开发结构：`modules.js` 负责站点识别与配置，`site-common.js` 为通用界面词表，六个 `site-*.js` 为网站独立词表，`sites.js` 为新增网站共用渲染器；市集仍由 `main.js` 和 `bridge.js` 负责。

游戏术语使用流亡编年史与官方台服的中文文本，显示繁体游戏译名。新增网站的普通界面标签为本项目整理的中文译文，未冒充官方游戏译名。

## 安装（Chrome）

1. 解压 `poe2-trade-zh.zip` 到一个长期保留的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后的 **extension** 文件夹，里面应有 `manifest.json`。
5. 打开 https://www.pathofexile.com/trade2/ ，按网站要求登录自己的账号，然后刷新页面。
6. 点击浏览器扩展按钮，可关闭汉化、开启结果双语、导出未匹配文字。

不要同时启用其他 PoE 市集汉化插件。移动或删除安装文件夹会影响已加载的插件。

## 功能

- 市集装备筛选区新增「筛选方案」：保存当前尚未提交的条件、按名称或条件摘要查找、完整套用、更新、重命名、删除与撤销删除。包含联赛、交易状态、装备、词缀及数值、价格和排序；套用后点击市集「搜索」获取结果。
- 方案保存在当前浏览器的扩展本地存储中，刷新后保留，关闭汉化仍可使用；不提供云同步，以物易物页面不显示此入口。套用会替换当前装备筛选条件，修改后需点击「更新方案」或「保存新方案」。卸载扩展会清除方案。
- 已失效的联赛、词缀 ID 或筛选字段会阻止套用并提示；无法保证检测所有上游选项与语义变化。删除可在当前页面撤销最近一次操作。
- 筛选标题、选项、物品和词缀搜索数据中文化；下拉数据保留英文，支持搜索中英文。
- 装备结果、物品名、词缀、动态新增结果汉化；原文可通过悬停查看。
- 保留词缀数值、搜索 ID、物品原始 name/type、选项值和交易请求。保护玩家名称、输入内容及密语。
- 本地内置词库，不需要台服登录来下载译文，不请求账号或 Cookie 权限。
- 不认识的文本保留英文，可在当前页面导出缺失清单。

## 更新与开发

普通使用无需安装 Node 或 Python。源码包提供采集脚本和词库构建工具：

```powershell
npm ci
python tools/update-data.py --refresh
npm test
```

需要 Python 3、Node.js、Windows 自带 tar、Chrome 和 Edge。`npm test` 使用隔离测试配置，不读取个人浏览器账号。更新过程保存来源摘要并校验当前官方数据覆盖；如果校验失败，恢复原有词库。

`package-lock.json` 锁定开发依赖，使用 `npm ci` 安装。CI 在每次分支推送、PR 和发布 tag 时执行完整 `npm test`，包括浏览器 DOM/API、真实 MV3 扩展加载和多站点集成测试；全部通过才允许发布。CI 使用 `npx playwright install --with-deps chromium` 安装配套浏览器，并设置 `TEST_BROWSER_CHANNEL=chromium`，本地也可使用同样配置。测试以模拟站点响应运行，不访问真实账号。

其他站点的动态汉化按变更子树合并扫描，仅首次加载和设置/站点模块变化时扫描全页。六个普通站点均在局部句子范围恢复英文后重新翻译，支持跨节点数值更新、双语和关闭恢复；具有显式 `value` 的下拉选项只翻译标签。

词库更新完成后，在 `chrome://extensions` 点击扩展卡片上的刷新按钮，再刷新市集。

2026-09-20 逐站校对范围、修复与访问限制见 [TRANSLATION_REVIEW.md](TRANSLATION_REVIEW.md)。公开页面采样结果保存在 `tests/live-sites-check.json`；可用 `node tests/live-sites-check.cjs` 重新检查（此命令访问真实网站，不属于离线测试套件；支持 `TEST_BROWSER_CHANNEL=chromium`）。采样统计是候选词库匹配数，不代表完整扩展翻译覆盖率。
